# Pizza Sales Analysis Dashboard

## 📊 Project Overview

A comprehensive data analytics project that analyzes pizza sales patterns, customer behavior, and revenue trends. This project demonstrates proficiency in **data analysis, business intelligence, and Power BI visualization**.

---

## 🎯 Objectives

- Analyze sales performance across different pizza categories and time periods
- Identify key revenue drivers and customer purchasing patterns
- Create interactive dashboards for data-driven decision making
- Optimize reporting processes for stakeholder insights

---

## 🛠️ Technical Stack

### Tools & Technologies
- **Business Intelligence:** Power BI
- **Database Management:** T-SQL, SQL Server
- **Data Analysis:** SQL Queries, Data Modeling, Trend Analysis
- **Visualization:** Interactive Dashboards, Charts, KPIs

### Skills Demonstrated
- Data extraction, transformation, and loading (ETL)
- SQL query optimization
- Dashboard design and development
- Business analytics and insights generation
- Data-driven decision support

---

## 📈 Key Features

✅ **Interactive Dashboards** - Multi-page Power BI dashboards with drill-down capabilities  
✅ **Sales Analytics** - Revenue analysis by product category, time period, and customer segments  
✅ **Trend Analysis** - Identification of seasonal patterns and growth opportunities  
✅ **Performance Metrics** - KPIs including total revenue, order count, and average order value  
✅ **Optimized Queries** - Efficient SQL queries for real-time data retrieval  

---

## 🔍 Key Insights Generated

- **Revenue Trends:** Identified top-performing pizza categories and seasonal demand patterns
- **Customer Analysis:** Analyzed purchasing behavior across different customer segments
- **Sales Optimization:** Recommendations for product mix and promotional strategies
- **Performance Metrics:** Tracked KPIs for ongoing business monitoring

---

## 📊 Dashboard Components

1. **Sales Overview Dashboard**
   - Total Revenue, Order Count, Average Order Value
   - Sales by Pizza Category and Size
   - Monthly and Weekly Trends

2. **Customer Analytics Dashboard**
   - Customer segmentation analysis
   - Purchase frequency and patterns
   - Top customers and revenue contribution

3. **Detailed Analytics**
   - Product-level performance metrics
   - Time-series analysis
   - Comparative analysis across dimensions

---

## 🚀 How to Use

1. **Open Power BI File**
   - Download `pizza.pbix`
   - Open in Power BI Desktop

2. **Connect Data Source**
   - Update connection strings to your SQL Server database
   - Refresh data to view latest analytics

3. **Explore Dashboards**
   - Navigate through different dashboard pages
   - Use filters and slicers for customized views
   - Drill-down to detailed transaction-level data

4. **SQL Queries**
   - Execute SQL scripts in `sql_queries/` folder
   - Modify queries for specific business requirements

## 📋 Data Requirements

The project works with pizza sales data containing:
- Order information (Order ID, Date, Quantity)
- Product details (Pizza Type, Category, Size, Price)
- Customer information (if available)
- Transaction details (Revenue, Discounts)
